# ADR 0018: การแชร์ Note แบบอ่านอย่างเดียวผ่านลิงก์ (Share Link) อยู่ใน Module Notes

## สถานะ
ยอมรับแล้ว (ตัดสินใจใน wayfinder map-v2, ticket 058/059/061 — ยังไม่ได้ implement) ยกเลิก non-goal "ไม่มีการแชร์/ทำงานร่วมกันของ note" **เฉพาะการแชร์แบบอ่านอย่างเดียว** — การทำงานร่วมกัน (collaboration), real-time และ version history ยังเป็น non-goal

## บริบท
requirements v2 ต้องการให้ผู้ใช้แชร์ Note ให้คนนอกดูผ่านลิงก์ เห็นเฉพาะ Note ที่แชร์และทุกอย่างใต้ Note นั้น ปัจจุบันทุก endpoint ยกเว้นล็อกอินต้องมี token การแชร์จึงเป็นจุดแรกที่เปิดให้ **คนที่ไม่ล็อกอินอ่านข้อมูลผ่าน API** และแบบจำกัดอีเมลต้องพิสูจน์ได้ว่าผู้เปิดเป็นเจ้าของอีเมล (ADR-0017) ขอบเขตการแชร์คือ subtree ของ Note ซึ่งอยู่ใน Module Notes (ADR-0013) พร้อมไฟล์แนบ (ADR-0015)

## การตัดสินใจ
- **การแชร์อยู่ใน Module Notes** (ไม่สร้าง Module Sharing แยก) เพื่อตรวจ "Note นี้อยู่ใต้ Note แม่ที่แชร์ไหม" ได้ตรงๆ ใน schema เดียว และไม่ต้องทำสำเนาข้อมูลลำดับชั้น/ความเป็นเจ้าของไว้ใน Module อื่น
- **รูปแบบ**: Public (ใครมีลิงก์ก็เปิดได้ ไม่ต้องมีบัญชี) หรือ จำกัดอีเมล (ผู้รับต้องล็อกอินด้วยบัญชีที่อีเมลตรงกับรายการ — บัญชีที่ล็อกอินได้ทุกบัญชียืนยันอีเมลแล้วตาม ADR-0017); วันหมดอายุเป็นตัวเลือก (ไม่ตั้ง = ไม่หมดอายุ)
- **Note หนึ่งมีหลายลิงก์** ลิงก์ละการตั้งค่า ยกเลิกแยกกัน ลิงก์ของ Note แม่กับลูกอิสระต่อกัน เจ้าของ ปิดลิงก์ทันที / เปลี่ยนรูปแบบ / เพิ่ม-ลบอีเมล / แก้วันหมดอายุ ได้
- **ขอบเขต = "ทุกอย่างใต้ Note แม่ ณ ตอนเปิดดู"** (ไม่ใช่ภาพถ่าย): เพิ่มลูกใหม่ผู้รับเห็นทันที, ย้ายออกแล้วหาย, ย้ายเข้ามาแล้วเห็น, ลูกที่ลบหายและกลับเมื่อกู้, ลบแม่ที่แชร์ → ลิงก์ใช้ไม่ได้และกลับมาใช้ได้เมื่อกู้แม่, ย้ายแม่ไปใต้ Note อื่น → ลิงก์ยังใช้ได้ ผู้รับไม่เห็นว่าอยู่ใต้ใคร
- **ผู้รับเห็น**: ชื่อและเนื้อหาแบบอ่านอย่างเดียว, ต้นไม้ของ Note ลูก, Category, Description, วันที่สร้าง/แก้ไขล่าสุด, รูปและไฟล์แนบของ Note ในขอบเขต; **ไม่เห็น**: การค้นหา, ชื่อ/อีเมลเจ้าของ, ชื่อ Note ที่อยู่เหนือแม่ที่แชร์
- ไฟล์แนบเปิดได้เฉพาะของ Note ในขอบเขต และปิด/หมดอายุลิงก์แล้วเปิดไม่ได้ทันที (API ส่งไฟล์เอง ตรวจสิทธิ์ทุกครั้ง ตาม ADR-0015)
- ข้อความเมื่อเข้าไม่ได้: **หมดอายุบอกแยก**; กรณีอื่น (ผิด/ไม่มี/ถูกปิด, อีเมลไม่อยู่ในรายการ, Note แม่ถูกลบ) ข้อความเดียวกัน "ลิงก์นี้ใช้ไม่ได้" ไม่บอกเหตุผล
- ไม่ติดตามว่าใครเปิดดู

## ผลที่ตามมา
- ต้องมี public read path (ไม่ต้องล็อกอิน) ใน `Web.Jotwai` พร้อมการป้องกันการยิงลิงก์ซ้ำๆ (rate limit) และรหัสลิงก์ที่เดาไม่ได้ — รายละเอียดเป็นขั้นออกแบบ
- Description ที่ AI สร้างจะถูกคนนอกเห็น ผู้ใช้ควรรู้ข้อนี้; ควรมีตัวบ่งชี้ใน UI ว่า Note ใดถูกแชร์อยู่ (กันย้าย Note เข้ามาใต้แม่ที่แชร์โดยไม่รู้ตัว)
- แชร์แบบจำกัดอีเมลจะปลอดภัยก็ต่อเมื่อการยืนยันอีเมล (ADR-0017) ถูก build แล้ว
- Module Notes ใหญ่ขึ้น (Note + ลำดับชั้น + ไฟล์แนบ + การแชร์) ยอมรับเพื่อไม่ต้องทำสำเนาข้อมูลข้าม Module
