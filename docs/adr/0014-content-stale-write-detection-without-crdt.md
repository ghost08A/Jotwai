# ADR 0014: ตรวจการบันทึกเนื้อหาทับเวอร์ชันที่เก่ากว่า โดยไม่ใช้ CRDT และไม่รวมข้อความอัตโนมัติ

## สถานะ
ยอมรับแล้ว (ตัดสินใจใน wayfinder map-v2, ticket 056 — ยังไม่ได้ implement)

## บริบท
Autosave บันทึกเนื้อหาทั้งก้อนหลังหยุดพิมพ์ 0.6 วินาที โดยไม่เช็กว่าของในฐานข้อมูลเป็นเวอร์ชันที่แท็บนั้นเปิดมาหรือไม่ ผู้ใช้ที่เปิด Note เดียวกันหลายแท็บ/หลายอุปกรณ์จึงเขียนทับกันเงียบๆ ได้ ทางเลือกที่ research พบมีทั้งตรวจเวอร์ชัน (token ของแถว, ETag/If-Match), รวมข้อความอัตโนมัติ และ CRDT แบบ Yjs/Tiptap Collaboration ซึ่งต้องมี sync server เพิ่มและเก็บเนื้อหาเป็นรูปแบบของมันเอง ชนกับกฎโปรเจกต์ว่า Markdown เป็น source of truth และห้ามเพิ่มระบบ real-time/push หรือ version history โดยไม่ปรึกษา

## การตัดสินใจ
- **ตรวจการชนตอนบันทึกเนื้อหา**: ถ้าแท็บบันทึกด้วยข้อมูลที่ไม่ใช่เวอร์ชันล่าสุด **ไม่เขียนทับ** หยุด autosave ของแท็บนั้น และให้ผู้ใช้เลือก: โหลดเวอร์ชันล่าสุด / ใช้ของแท็บนี้เขียนทับ / คัดลอกข้อความเก็บก่อนแล้วโหลดใหม่
- **ไม่ใช้ CRDT/Yjs ไม่รวมข้อความอัตโนมัติ** (research ไม่พบแหล่งรองรับการรวมข้อความ Markdown ยาวแบบอัตโนมัติ)
- ป้องกันเฉพาะ **เนื้อหา** (การเปลี่ยนชื่อ/ย้าย/Category จากอีกแท็บไม่นับเป็นการชน); Note ถูกลบจากอีกแท็บ → ให้เลือกคัดลอก/กู้คืนแล้วบันทึก/ทิ้ง
- แท็บที่กลับมาโฟกัส ให้หน้าเว็บถามเซิร์ฟเวอร์ว่ามีเวอร์ชันใหม่ไหม และโหลดให้เองถ้าไม่มีข้อความค้าง (ไม่ใช่ push)
- เวอร์ชันของแท็บที่ชนอยู่ **เฉพาะในเบราว์เซอร์** ไม่เก็บสำเนาฝั่งเซิร์ฟเวอร์ (ไม่ใช่ version history); เตือนก่อนปิดแท็บเฉพาะช่วงที่ค้างสถานะชน
- ปุ่มยืนยันของ **Content Polish** และ **Merge** ต้องตรวจว่าเนื้อหาไม่เปลี่ยนหลังที่ AI คำนวณ ก่อนเขียนทับ

## ผลที่ตามมา
- วิธีเก็บเลขเวอร์ชัน/รูปแบบ API และการบันทึกตอนปิดแท็บ (`sendBeacon` ตั้ง header ไม่ได้ จำกัด 64 KiB) ยังต้องออกแบบ
- ถ้าอนาคตต้องการแก้ร่วมกันแบบสดหรือประวัติเวอร์ชัน ต้องตัดสินใหม่ — ADR นี้ไม่ได้ปิดทางไว้ แต่ไม่ได้เตรียมพื้นไว้ให้ด้วย
